# Eros

- Docker Compose only; Python 3.14/pip. Prefer real-host Docker verification. Local Python checks always use `uv run --no-project --python 3.14`; environments, locks, caches and checks stay untracked/outside the repository.
- `eros/`: sources, processing, runtime, API and plain HTML/CSS/JS. `emby-plugin/Eros/`: Emby providers. C# changes must rebuild tracked `emby-plugin/Eros.dll`; Python/plugin versions remain aligned at 0.4.0.
- JSON settings: `/data/settings.json`; SQLite runtime: `/data/runtime/<metadata-path hash>/runtime.sqlite3`. Keep the service lock; no compatibility/migrations, ORM, persistent source/translation caches or automatic fetch tasks. Only user options belong in settings.
- Media is read-only. Exact parent names are catalog codes; preserve full prefixes and require user correction for invalid/duplicate codes. NFO and images use media filename stems; metadata folders contain only NFO/images. NFO is authoritative; runtime stores indexes/tasks only. The plugin reads `/eros-metadata` directly, never the database.
- NFO: Eros uniqueid, producer studio, distinct publisher/label extensions, separate genres/tags. Omit duplicate publisher/label values; never turn them into studios/tags/genres. Preserve valid output on failure. Posters use bundled licensed YuNet/OpenCV 2:3 crops with center fallback; other images retain original bytes.
- DMM, JavDB (API then web), JavBus, FC2, AVSOX; JavDB precedes JavBus. One work/translation at a time. Site intervals apply to metadata; images use 1 second. Port 9307; metadata `/data/metadata`; FlareSolverr `http://flaresolverr:8191/v1`, blank disables it.
- Send only titles/descriptions to translation with the exact user prompt; no actor fields, placeholders or script conversion. Test translation only with benign text. Actor aliases/rules use JSON; missing names are normal. Only ambiguous aliases need confirmation; explicit male actors skip automatic alias/portrait processing.
- gfriends portraits live in `metadata/actors`, named exactly as NFO actors. Try primary names then safe aliases; retain old portraits on failure. Alias search displays primary names while preserving actual NFO names for portrait operations.
- Shared work details, read-only codes, preview before save, disabled unavailable actions, keyboard access and system theme. Tasks/items are separate; progress writes the current item. Previews stay in memory; cancellation stops workers, retains records and restores work statuses. Task numbers never reuse; no separate log store.
- Short Chinese UI names (2–6 characters), descriptions ≤20; preserve protocol identifiers. Dates use 年月日, work-progress timestamps YYYY/MM/DD. Comments explain boundaries, not obvious steps. Keep structure small; preserve real metadata and keep backups outside the repository.
- Ship `docker-compose.example.yml` only. Actual Compose files/data are untracked. Deploy/restart Eros and Emby through Compose.
